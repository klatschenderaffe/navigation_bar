# Projektname: Navigation Bar

![Alt-Text](/src/assets/navigation_bar.png)

## Projektübersicht

Dieses Projekt ist ein persönliches Übungsprojekt, das ich entwickelt habe, um meine Kenntnisse im Umgang mit `React Router DOM` zu vertiefen. Ziel dieser Übung ist es, ein besseres Verständnis für die Funktionsweise und Anwendungsmöglichkeiten von `React Router DOM` zu erlangen.

## Funktionsweise

- **Navigation durch drei leere Seiten**: Zu Übungszwecken wurden die zusätzlichen Seiten bewusst leer gelassen, um den Fokus ausschließlich auf die Navigation zu legen.
